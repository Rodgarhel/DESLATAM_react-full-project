# React  Proyect: Mamma Mia Pizzeria!

## 🔗 Live Demo
(https://rodgarhel.github.io/DESLATAM_react-full-project/)

## Description
An evolving proyect using React. The goal is to, step by step, learn to use the tool by developing a webpage for a fantasy Pizza place. 

### V 0.7
Mainly added a global token to reroute to specific pages depending if "logged in" or not. The token also block  certain  features.
Changed some route  functions to work with NavLink and {Navigate()}

### V 0.6
Changed the whole project so it now uses context. The API, cart total and button functionalities are now managed by the CartContext component.

### V 0.5
Added Routes functionality, making it possible to navigate the web. Now you can accese the different sub-pages for   testing, including profile and "404" page. 
FOr now, links on navbar are set to visible and I yet have to sync global values, like overall total, and user validation. 
### V 0.4
Added a Pizza.jsx file for each pizza's details, for future implementation. Also changed the pizzas data, for an API link to a local URL.  
### V 0.3
Added a cart section, that works using UseState and calling menu data from a js file. 
### V 0.2
Login and register page. For now this page is replacing the home page. You can still find the home page in the files. 
This version explores how to use forms and states to validate registration or login.
### V 0.1
Structure. Just the main structure of the landing page, including buttons, initial tokens and components.
